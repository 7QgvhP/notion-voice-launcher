# 0006. ツールチェーンのバージョンを固定せず自動で探す

- ステータス: Accepted
- 日付: 2026-09-20 以前

## 背景（Context）

`build.ps1` は、JDK と Android SDK（build-tools、platform）のフォルダを参照する。バージョン番号をパスに書くと、ツールを更新するたびにスクリプトの修正が必要になる。

## 決定内容（Decision）

- バージョン番号を固定せず、パターン（`jdk\jdk-*`、`sdk\build-tools\*`、`sdk\platforms\android-*`）に一致するフォルダのうち、名前の降順で先頭のものを使う。
- 探す場所の既定値は `%USERPROFILE%\android-build-tools` とし、環境変数 `NVL_TOOL_ROOT` で変えられるようにする（v1.1.4 で、個人環境に依存した絶対パスから変更した）。

## 理由と検討した代替案（Consequences / Alternatives）

- JDK や build-tools を更新しても、ビルドが壊れない。他の PC でもそのまま動く。
- 一致するフォルダがない場合は、どのパターンに一致しなかったかを示して停止する。
- 名前の降順で選ぶため、バージョン番号の桁数が異なる場合（例: `9` と `10`）に、最新でないものが選ばれる可能性がある。
- 検討した代替案: パスにバージョン番号を書く（以前の形）。ツールの更新のたびに修正が必要になるため変更した。
